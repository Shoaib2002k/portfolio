## 🛠️ Getting Started (Local Setup)

```bash
# Clone the repository
git clone https://github.com/Shoaib2002k/portfolio.git

# Navigate to frontend
cd portfolio/portfolio-frontend

# Install dependencies
npm install

# Start development server
npm start
```
